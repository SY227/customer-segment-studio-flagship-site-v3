# V3.1 Tabbed Commercial Layout

V3.1 changes the flagship site from a long-scroll marketing story into five persistent top-level content tabs:

1. Overview
2. See the Field
3. Understand Groups
4. Make the Move
5. Business Value

The Overview keeps the approved composition: dark horizontal navigation, large serif headline on the left, living-segment-map story card on the right, nine-segment character rail below, and a dedicated segmentation-review card.

The content is not rewritten into a new product. Existing screenshots, segment labels, product boundaries, RFM explanation, and review flow are preserved. The tabs change presentation and reading order only.
