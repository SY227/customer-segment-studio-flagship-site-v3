# Character sources and mapping

The individual character presentation is grounded in the current Customer Segment Studio source-defined mapping:

- Best Customers — Knight
- Loyal Buyers — Ranger
- New Buyers — Druid
- At-Risk VIPs — Barbarian
- Growing Buyers — Engineer
- Occasional Buyers — Rogue
- Dormant VIPs — Barbarian, shown in its original warm KayKit colors on the marketing site
- Light Repeaters — Mage
- Inactive Customers — Hooded Rogue

The marketing site uses compact presentation renders of those existing character identities. It does not change the live product, its data model, or its Three.js scene.

KayKit Adventurers assets are distributed under CC0. The original license text is retained in `docs/licenses/kaykit-adventurers-license.txt`.
